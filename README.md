# EcommerceOrg

Projeto preparado para publicação no GitHub.

## Estrutura
- backend/
- frontend/

## Como executar
1. Crie um ambiente virtual.
2. Instale as dependências do projeto.
3. Configure as variáveis em `backend/.env` usando `backend/.env.example` como modelo.
4. Execute o backend e o frontend conforme a implementação do projeto.
